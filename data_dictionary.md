# Data Dictionary — Café datasets

All data is **synthetic**, generated by `generate_cafe_data.py`. Every relationship is
engineered on purpose so each notebook demonstrates a specific idea. Re-run the
generator to reproduce; change `SEED` for a fresh draw with the same structure.

## `cafe_daily.csv` — 731 rows (2024-01-01 → 2025-12-31, one row per day)

| Column | Meaning | Used for (N = notebook) |
|---|---|---|
| `date` | Calendar date | Time-trend (spurious) demo |
| `day_of_week` | Monday…Sunday | Regression feature (N4) |
| `is_weekend` | 1 = Sat/Sun | Confounder in promo demo (N3) |
| `temperature_c` | Daily temperature (°C) | The key driver / confounder throughout |
| `iced_drink_sales` | Units sold | **Positive** corr with temp (N1, N2) |
| `hot_drink_sales` | Units sold | **Negative** corr with temp (N1, N2) |
| `cold_brew_sales` | Units sold | Confounding demo — driven by temp (N3) |
| `salad_sales` | Units sold | Confounding demo — driven by temp (N3) |
| `foot_traffic` | Customers/day | Strong predictor (N4); grows over time |
| `barista_shoe_size` | EU size of barista on shift | **Near-zero** / data-mining noise (N1, N2, N3) |
| `social_followers` | Cumulative social media followers | **Spurious** shared time trend (N3) |
| `promo_active` | 1 = promo running | Observational (confounded) effect (N3) |
| `discount_pct` | Discount applied (0–40%) | **Non-linear** inverted-U vs profit (N2) |
| `daily_revenue` | Revenue (€) | ML target (N4); spurious-trend partner |
| `daily_profit` | Profit (€) | Inverted-U outcome vs discount (N2) |
| `pastry_demand` | Pastries sold | Regression target (N4) |

> One **outlier** is injected at row index 40 (a cold February day with a one-off iced-drink
> catering order). It sits off the temperature trend and is used in Notebook 2, Part 3.

## `cafe_promo_experiment.csv` — 300 rows
Randomised A/B test. `promo_active` is assigned at random, **independent of `is_weekend`**, so
the simple revenue gap (~€48) is close to the true effect (€40). Contrast with the confounded
observational gap (~€74) in `cafe_daily.csv`. Used in **Notebook 3, Part 3**.

| Column | Meaning |
|---|---|
| `day` | Test day number |
| `is_weekend` | 1 = weekend |
| `promo_active` | 1 = promo (randomly assigned) |
| `daily_revenue` | Revenue (€) |

## `cafe_two_stores.csv` — 180 rows
Two locations. **Within** each store, more staff → higher satisfaction (positive). **Pooled**
across stores the relationship reverses (negative), because the busy Downtown store runs high
staff *and* lower baseline scores. This is Simpson's paradox. Used in **Notebook 3, Part 4**.

| Column | Meaning |
|---|---|
| `store` | Downtown or Suburb |
| `staff_on_shift` | Staff count |
| `customer_satisfaction` | Score (0–100) |
